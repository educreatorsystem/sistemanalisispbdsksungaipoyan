# Sistem Analisis PBD – SEKOLAH KEBANGSAAN SUNGAI POYAN

Sistem asal dikekalkan tanpa PWA. Hanya nama, lencana, lima tetapan sambungan dikemas kini.

## Terbitkan di GitHub Pages
1. Muat naik `index.html` ke direktori root repository.
2. Dalam Settings > Pages, pilih Deploy from a branch, `main`, `/ (root)`.
3. Pastikan Google Sheets diterbitkan sebagai CSV dan URL Apps Script dibenarkan mengikut tetapan akses yang sesuai.

**Nota:** Lencana dimuatkan daripada hos imej luar (iili.io); paparan lencana memerlukan pautan tersebut tersedia.
